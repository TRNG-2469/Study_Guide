# Phase 12 — Backend Integration

## What You Will Learn

This is the final phase. You will replace the simulated in-memory `StudentService` with real HTTP calls to your Spring Boot REST API backed by PostgreSQL. When this phase is complete, the Student Management System will be a genuine full-stack application.

By the end of this phase:
- `HttpClient` makes GET, POST, PUT, DELETE requests to Spring REST endpoints
- HTTP errors are caught, categorised, and displayed as user-friendly messages
- Loading spinners appear during every network request
- CORS is configured on the Spring Boot side to accept Angular's requests
- Environment configuration separates the dev API URL from a production URL

### Spring Boot REST Controller

```java
// StudentController.java
@RestController
@RequestMapping("/api/students")
@CrossOrigin(origins = "http://localhost:4200")   // Allow Angular's origin
public class StudentController {
    private final StudentService service;

    public StudentController(StudentService service) {
        this.service = service;
    }

    @GetMapping
    public List<Student> getAll() {
        return service.findAll();
    }

    @GetMapping("/{id}")
    public ResponseEntity<Student> getById(@PathVariable Long id) {
        return service.findById(id)
            .map(ResponseEntity::ok)
            .orElse(ResponseEntity.notFound().build());
    }

    @GetMapping("/search")
    public List<Student> search(@RequestParam String q) {
        return service.search(q);
    }

    @PostMapping
    @ResponseStatus(HttpStatus.CREATED)
    public Student create(@RequestBody @Valid Student student) {
        student.setId(null);   // Ensure ID is generated by the database
        return service.save(student);
    }

    @PutMapping("/{id}")
    public ResponseEntity<Student> update(
            @PathVariable Long id,
            @RequestBody @Valid Student student) {
        return service.findById(id)
            .map(existing -> {
                student.setId(id);
                return ResponseEntity.ok(service.save(student));
            })
            .orElse(ResponseEntity.notFound().build());
    }

    @DeleteMapping("/{id}")
    public ResponseEntity<Void> delete(@PathVariable Long id) {
        return service.findById(id)
            .map(s -> { service.delete(id); return ResponseEntity.noContent().<Void>build(); })
            .orElse(ResponseEntity.notFound().build());
    }
}
```

### `@CrossOrigin` vs. Global CORS

`@CrossOrigin(origins = "http://localhost:4200")` on the controller allows Angular's dev server to reach this endpoint. For a cleaner production setup, configure CORS globally:

```java
// WebConfig.java
@Configuration
public class WebConfig implements WebMvcConfigurer {
    @Override
    public void addCorsMappings(CorsRegistry registry) {
        registry.addMapping("/api/**")
                .allowedOrigins("http://localhost:4200")
                .allowedMethods("GET", "POST", "PUT", "DELETE", "OPTIONS")
                .allowedHeaders("*");
    }
}
```

## 4. Rewriting `StudentService` with `HttpClient`

### `src/app/services/student.service.ts`

```typescript
import { Injectable, inject, signal, computed } from '@angular/core';
import { HttpClient, HttpParams } from '@angular/common/http';
import { Observable, tap, catchError, of, finalize } from 'rxjs';
import { Student } from '../models/student.model';
import { environment } from '../../environments/environment.development';

@Injectable({ providedIn: 'root' })
export class StudentService {
  private http = inject(HttpClient);
  private readonly apiUrl = `${environment.apiUrl}/students`;

  // Local signal cache — updated after every successful HTTP write
  private _students = signal<Student[]>([]);
  private _loading  = signal<boolean>(false);
  private _error    = signal<string | null>(null);

  // Public read-only signals
  readonly students    = this._students.asReadonly();
  readonly loading     = this._loading.asReadonly();
  readonly error       = this._error.asReadonly();
  readonly totalCount  = computed(() => this._students().length);
  readonly activeCount = computed(() => this._students().filter(s => s.status === 'active').length);

  // ─── READ ─────────────────────────────────────────────────────────────────

  loadAll(): void {
    this._loading.set(true);
    this._error.set(null);

    this.http.get<Student[]>(this.apiUrl)
      .pipe(
        tap(students => this._students.set(students)),
        catchError(err => {
          this._error.set('Failed to load students. Please try again.');
          return of([]);
        }),
        finalize(() => this._loading.set(false))
      )
      .subscribe();
  }

  getById$(id: number): Observable<Student> {
    return this.http.get<Student>(`${this.apiUrl}/${id}`);
  }

  search$(term: string): Observable<Student[]> {
    const params = new HttpParams().set('q', term);
    return this.http.get<Student[]>(`${this.apiUrl}/search`, { params });
  }

  // ─── CREATE ───────────────────────────────────────────────────────────────

  add$(student: Omit<Student, 'id'>): Observable<Student> {
    return this.http.post<Student>(this.apiUrl, student).pipe(
      tap(created => {
        // Update the local signal cache immediately
        this._students.update(list => [...list, created]);
      })
    );
  }

  // ─── UPDATE ───────────────────────────────────────────────────────────────

  update$(student: Student): Observable<Student> {
    return this.http.put<Student>(`${this.apiUrl}/${student.id}`, student).pipe(
      tap(updated => {
        this._students.update(list =>
          list.map(s => s.id === updated.id ? updated : s)
        );
      })
    );
  }

  // ─── DELETE ───────────────────────────────────────────────────────────────

  delete$(id: number): Observable<void> {
    return this.http.delete<void>(`${this.apiUrl}/${id}`).pipe(
      tap(() => {
        this._students.update(list => list.filter(s => s.id !== id));
      })
    );
  }
}
```

**Design decisions explained:**

- `loadAll()` is a **void method** that sets the signal — components call it once to populate the cache; the signal reactively updates the UI.
- Write methods (`add$`, `update$`, `delete$`) return **Observables** — the component subscribes and handles success/failure (navigate on success, show error on failure).
- After each write, `tap()` updates the local signal cache immediately so the UI reflects the change without a full reload.
- `_loading` and `_error` signals give every component a reactive loading and error state with zero extra code.
- `finalize()` runs regardless of success or error — guaranteed to clear the loading state.

## 6. HTTP Error Interceptor

An **interceptor** runs on every HTTP request and response. A global error interceptor catches all HTTP errors in one place rather than handling them in every component.

### Generate the interceptor

```bash
ng generate interceptor interceptors/error
```

### `src/app/interceptors/error.interceptor.ts`

```typescript
import { HttpInterceptorFn, HttpErrorResponse } from '@angular/common/http';
import { catchError, throwError } from 'rxjs';

export const errorInterceptor: HttpInterceptorFn = (req, next) => {
  return next(req).pipe(
    catchError((error: HttpErrorResponse) => {
      let message = 'An unexpected error occurred.';

      if (error.status === 0) {
        // Network error — server not reachable
        message = 'Cannot reach the server. Is Spring Boot running?';
      } else if (error.status === 400) {
        message = error.error?.message ?? 'Invalid request data.';
      } else if (error.status === 404) {
        message = 'The requested resource was not found.';
      } else if (error.status === 409) {
        message = 'A conflict occurred — the record may already exist.';
      } else if (error.status >= 500) {
        message = 'A server error occurred. Please try again later.';
      }

      console.error(`HTTP ${error.status}: ${message}`, error);

      // Re-throw with the user-friendly message attached
      return throwError(() => new Error(message));
    })
  );
};
```

Register it in `app.config.ts` as shown in Step 1 above.

## 7. Updating `StudentFormComponent` for HTTP

The form now calls `add$()` and `update$()` which return Observables:

### Updated `onSubmit()` in `StudentFormComponent`

```typescript
import { Component, inject, OnInit } from '@angular/core';
import { FormBuilder, FormGroup, Validators, ReactiveFormsModule, AbstractControl, ValidationErrors } from '@angular/forms';
import { ActivatedRoute, Router, RouterLink } from '@angular/router';
import { StudentService } from '../../services/student.service';
import { Student } from '../../models/student.model';

export class StudentFormComponent implements OnInit {
  private fb = inject(FormBuilder);
  private route = inject(ActivatedRoute);
  private router = inject(Router);
  readonly studentService = inject(StudentService);

  form!: FormGroup;
  isEditMode = false;
  editStudentId: number | null = null;
  pageTitle = 'Add Student';
  submitLabel = 'Add Student';
  submitError: string | null = null;
  isSubmitting = false;

  // ... (buildForm and other methods unchanged)

  onSubmit(): void {
    if (this.form.invalid) {
      this.form.markAllAsTouched();
      return;
    }

    this.isSubmitting = true;
    this.submitError = null;

    if (this.isEditMode && this.editStudentId !== null) {
      const existing = this.studentService.students().find(s => s.id === this.editStudentId)!;
      const updated: Student = { ...existing, ...this.form.value };

      this.studentService.update$(updated).subscribe({
        next: student => this.router.navigate(['/students', student.id]),
        error: (err: Error) => {
          this.submitError = err.message;
          this.isSubmitting = false;
        }
      });

    } else {
      const newStudent = {
        ...this.form.value,
        enrolmentDate: new Date().toISOString().split('T')[0],
      };

      this.studentService.add$(newStudent).subscribe({
        next: student => this.router.navigate(['/students', student.id]),
        error: (err: Error) => {
          this.submitError = err.message;
          this.isSubmitting = false;
        }
      });
    }
  }
}
```

## 8. Updating `StudentDetailComponent` for HTTP

```typescript
export class StudentDetailComponent implements OnInit {
  private route = inject(ActivatedRoute);
  private router = inject(Router);
  readonly studentService = inject(StudentService);

  student: Student | undefined;
  isDeleting = false;
  deleteError: string | null = null;

  ngOnInit(): void {
    const id = Number(this.route.snapshot.paramMap.get('id'));
    // Use the local signal cache first (instant); fetch fresh from API
    this.student = this.studentService.students().find(s => s.id === id);

    // Always fetch fresh data from the API for the detail view
    this.studentService.getById$(id).subscribe({
      next: student => this.student = student,
      error: () => this.router.navigate(['/not-found'])
    });
  }

  onDelete(): void {
    if (!this.student || !confirm(`Delete ${this.student.name}?`)) return;
    this.isDeleting = true;
    this.studentService.delete$(this.student.id).subscribe({
      next: () => this.router.navigate(['/students']),
      error: (err: Error) => {
        this.deleteError = err.message;
        this.isDeleting = false;
      }
    });
  }

  goBack(): void {
    this.router.navigate(['/students']);
  }
}
```

## 9. The `HttpClient` Methods Reference

```typescript
// All methods return Observable<T>

// GET — retrieve data
this.http.get<Student[]>('/api/students')
this.http.get<Student>('/api/students/1')
this.http.get<Student[]>('/api/students/search', { params: { q: 'alice' } })

// POST — create a resource
this.http.post<Student>('/api/students', newStudentBody)

// PUT — replace a resource
this.http.put<Student>('/api/students/1', updatedStudentBody)

// PATCH — partial update (if your API supports it)
this.http.patch<Student>('/api/students/1', { status: 'graduated' })

// DELETE — remove a resource
this.http.delete<void>('/api/students/1')
```

`HttpParams` builds query strings cleanly:

```typescript
const params = new HttpParams()

  .set('status', 'active')
  .set('page', '0')
  .set('size', '10');
```

## 10. End-to-End CRUD Flow

With both applications running (`ng serve` and `mvn spring-boot:run`), the complete flow for each operation:

### Read (GET)

```
StudentListComponent.ngOnInit()
  → studentService.loadAll()
  → HTTP GET http://localhost:8080/api/students
  → Spring: StudentController.getAll() → StudentRepository.findAll()
  → PostgreSQL: SELECT * FROM students
  → JSON response → Angular → _students.set(data) → UI re-renders
```

### Create (POST)

```
StudentFormComponent.onSubmit()
  → studentService.add$(newStudent)
  → HTTP POST http://localhost:8080/api/students   body: { name, email, ... }
  → Spring: StudentController.create() → StudentRepository.save()
  → PostgreSQL: INSERT INTO students
  → JSON response (with generated ID) → Angular → _students.update() → navigate to detail
```

### Update (PUT)

```
StudentFormComponent.onSubmit() [edit mode]
  → studentService.update$(updatedStudent)
  → HTTP PUT http://localhost:8080/api/students/1   body: { id: 1, name, email, ... }
  → Spring: StudentController.update() → StudentRepository.save()
  → PostgreSQL: UPDATE students SET ... WHERE id = 1
  → JSON response → Angular → _students.update() → navigate to detail
```

### Delete (DELETE)

```
StudentDetailComponent.onDelete()
  → studentService.delete$(id)
  → HTTP DELETE http://localhost:8080/api/students/1
  → Spring: StudentController.delete() → StudentRepository.deleteById()
  → PostgreSQL: DELETE FROM students WHERE id = 1
  → 204 No Content → Angular → _students.update() → navigate to /students
```
